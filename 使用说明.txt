个人英语生词本 - 使用说明
===========================

一、启动程序
------------
双击运行（或在命令行执行）：
    python main.py

首次启动会自动初始化数据库。若提示"内置词库为空"，请先执行数据导入
（见下方"数据说明"）。

二、主菜单功能
--------------
  1. 添加生词    输入不认识的英文单词，自动收录进生词本
  2. 今日学习    复习到期单词 + 学习新词（每日新词配额默认 20 个）
  3. 只学新词    只学习新收录的词，不做复习
  4. 查看生词本  分页浏览全部生词；输入编号查看完整词条（释义/例句/同根词/形近词）
  5. 学习统计    查看各状态词数、今日完成数、连续学习天数、薄弱词
  6. 导出备份    将生词本导出为 JSON（可完整恢复）与 CSV（表格查看）
  7. 设置        修改每日新词配额、日界时刻
  8. 批量导入生词 从文本文件（每行一词，# 注释）或直接粘贴多个单词批量收录
  0. 退出        退出前自动备份数据库（保留最近 7 天）

三、学习流程（核心）
--------------------
1. 程序先只显示【单词 + 音标】，你在心中回忆词义；
2. 按回车翻开答案，查看完整词条：
     词义（柯林斯双解，多义项分行）
     一句例句
     同根词（如 energy -> energetic）
     易混淆词（如 energy 与 emerge，每个带短释义）
3. 三档自评：
     [1] 认识    -> 间隔 1 天 -> 3 天 -> 逐步翻倍（SM-2 算法）
     [2] 模糊    -> 间隔减半，本次会话稍后复现一次
     [3] 不认识  -> 间隔重置，本次会话反复出现直到答对
4. 连续答对、间隔达到 21 天以上，单词标记为【已掌握】。

四、常见问题
------------
- 单词查不到？程序会给出拼写最接近的 3 个候选词，选编号即可直接收录。
- 学习中断？进度已即时保存，下次继续按到期规则调度。
- 复习积压？到期词按到期日排序，可分批完成；也可在"设置"中减少每日新词配额。
- 想换电脑/备份？用"导出备份"生成 JSON，重装后回复数据（开发版通过
  python -c 调用 vocab.stats.import_json 导入）。

五、数据说明
------------
词库来源（全部离线，无需联网）：
  - 释义/例句/星级：柯林斯高阶英汉双解词典（mdx 格式，36330 词条）
  - 词条底库/词频/词形变化：ECDICT 开源词库（340 万词条，MIT 协议）
  - 音标：ipa-dict 开源美式音标数据（125927 词，MIT 协议）
  - 词根词缀：WordRoots 开源词根表 + 算法词形归并

目录结构：
  data/vocab.db   生词本数据库（含内置词库与你的生词进度）
  backup/         自动备份与导出文件
  config.json     配置文件

如磁盘紧张，可删除 data/stardict.db（ECDICT 原始库，851MB，仅重装词库时需要）
与 data/ecdict-sqlite-28.zip（207MB 安装包）。
